# 打包与发布（Windows）

用 PyInstaller 把源码打成**文件夹版**桌面程序，并生成可分发的压缩包。
产物是 `dist/PA_Agent/`：`PA_Agent.exe` + `_internal/`。

## 一条命令

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_release.ps1
```

会依次执行：环境检查 → 全量回归测试 → 清理旧产物 → PyInstaller 构建 →
复制文档 → 压缩成 `dist/PA_Agent-v<版本>-win64.zip`。

常用参数：

| 参数 | 作用 |
|------|------|
| `-SkipTests` | 跳过回归测试（只想快速试构建时用，发布前不要用） |
| `-Tag v0.1.0` | 指定版本号，默认读 `pa_agent.__version__` |
| `-Publish` | 打完包后创建 Git tag、推送、用 `gh` 建 GitHub Release 并上传 zip |

`-Publish` 要求本机已 `gh auth login`（AidenOrz 账号），且 `github.com:443` 可直连；
被墙时先 `git -c http.proxy=http://127.0.0.1:7897 push origin <tag>`。

## 目录布局（用户视角）

```
PA_Agent/
  PA_Agent.exe
  _internal/            ← 只读：prompt_engineering/*.txt、Qt 插件、依赖库
  config/settings.json  ← 首次启动自动生成（含 API Key，DPAPI 加密）
  records/pending/      ← 分析记录
  logs/                 ← 运行日志
```

`pa_agent/config/paths.py` 里 `PROJECT_ROOT` 与 `BUNDLE_ROOT` 分别解析这两套根：
冻结运行时前者是 exe 所在目录（可写），后者是 `sys._MEIPASS`（只读）。
想改提示词又不重打包，把 `prompt_engineering/` 整个目录放到 **exe 同级**即可——
`_prompt_dir()` 会优先用它；也可以用环境变量 `PA_AGENT_PROMPT_DIR` 指定绝对路径。

## spec 文件里的取舍

`PA_Agent.spec` 的 `excludes` 是刻意写成清单的，改之前请先读注释：

- **必须排除其它 Qt 绑定**（`PyQt5`/`PySide6`/`shiboken*`）。本机 anaconda 环境里装了它们，
  一旦被收集，PyInstaller 会直接以「multiple Qt bindings」中止构建。
- **scipy 会顺带拖进 dask / torch**，`scipy.conftest` 里有测试期导入。不排除的话产物从
  ~390 MB 涨到 980 MB，而且与功能无关。
- **plotly / panel / playwright / pyarrow / polars / sklearn / statsmodels / tables / h5py** 等
  是 anaconda 基础环境的常见常驻包，本项目运行时不 import（可用
  `import pa_agent.gui.main_window` 后检查 `sys.modules` 验证）。排除它们把产物压到 ~390 MB。

数据源模块是**函数内延迟导入**的，因此 spec 用 `collect_submodules("pa_agent")` 兜底，
避免「测试时正常、打包后缺模块」。

## 已知限制

- 只构建 **onedir**（文件夹版），不打单文件。单文件每次启动都要解压 ~390 MB 到临时目录，
  启动要十几秒，且 `_MEIPASS` 里的 prompt 改写不生效。
- 没有做代码签名，Windows SmartScreen 首次运行会提示「未知发布者」。
- MetaTrader5 数据源要求本机装了 MT5 终端；打包产物**不含** MT5，运行时报
  `IPC initialize failed, MetaTrader 5 x64 not found` 属于预期（其它数据源不受影响）。

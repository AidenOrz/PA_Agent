# 数据源注册表与新增数据源（Baostock / Binance）

> 更新：2026-11-03
> 适用代码：`pa_agent/data/sources_registry.py`、`baostock_source.py`、`binance_source.py`

## 一、为什么要有注册表

数据源清单此前散落在 4 处，新增一个源要挨个改字符串元组：

| 位置 | 原来的写法 |
|------|-----------|
| `pa_agent/data/factory.py` | `DataSourceKind` Literal、`DATA_SOURCE_CHOICES`、`_HIDDEN_KINDS`、`_DEFAULT_SYMBOLS` |
| `pa_agent/config/settings.py` | 第二份 `DataSourceKind` Literal（还不含 yfinance）、`_coerce_legacy_data_source` 逐 kind 判断 |
| `pa_agent/data/market_defaults.py` | `if kind in ("akshare","eastmoney","tushare","westock")` |
| `pa_agent/gui/main_window.py` | 刷新间隔节流 `in ("akshare","eastmoney","tushare")`、代码占位提示、周期回落分支 |

现在这些判断全部改为查注册表。

## 二、注册表结构

```python
# pa_agent/data/sources_registry.py
SourceSpec(
    kind="baostock",              # 与 settings.general.last_data_source 对应
    label="Baostock（A股）",       # GUI 下拉与状态栏显示
    markets=frozenset({"cn_a"}),  # 能提供哪些市场的品种
    default_symbol="000001",
    default_timeframe="1d",
    ui_visible=True,              # 是否出现在 GUI 下拉
    placeholder="A股 6 位代码…",   # 品种输入框占位提示
    tooltip="Baostock（免费…）",   # 下拉框悬浮说明
    min_refresh_interval_ms=2500, # 刷新间隔下限（HTTP 源节流）
    supported_timeframes=(...),   # None = 由实例决定（MT5/TradingView）
    domestic=True,                # 国内（A 股）源，计入共用列表
)
```

派生量（都在同一模块）：

| 名称 | 含义 |
|------|------|
| `SOURCE_SPECS` | 全部数据源，顺序即 GUI 顺序 |
| `ALL_KINDS` / `UI_KINDS` / `HIDDEN_KINDS` | 全部 / 下拉可见 / 仅配置可用 |
| `DOMESTIC_A_SHARE_KINDS` | **国内数据源共用列表**（见下） |
| `kinds_for_market("cn_hk")` | 按市场反查数据源 |
| `is_domestic_a_share()` / `min_refresh_interval_ms()` / `source_placeholder()` / `source_default_timeframe()` / `source_supported_timeframes()` | 供 GUI 与 market_defaults 查询 |

## 三、「国内数据源」共用列表

```python
DOMESTIC_A_SHARE_KINDS  # ("baostock", "westock", "akshare", "eastmoney", "tushare")
```

由 `domestic=True` 派生，不再手写元组。使用点：

- `pa_agent/data/market_defaults.py` 的 `normalize_gold_symbol_for_kind()`：国内源把非 6 位输入回落到 `000001`。
- `pa_agent/gui/main_window.py` 的刷新间隔节流：读 `min_refresh_interval_ms()`。
- `pa_agent/gui/main_window.py` 的品种占位提示：读 `source_placeholder()`。
- `pa_agent/gui/main_window.py` 的周期回落：读 `source_supported_timeframes()` + `source_default_timeframe()`；
- `pa_agent/app_context.py` 启动时的周期归一：同上（原来只对 westock 硬编码）。

**WeStock 为什么算国内源**：它同时提供 A 股、港股、美股，标签里没写「A 股」，但它原生接受 6 位代码，
所以必须进这个列表。反过来 TradingView 也能取到 A 股代码，它只算「能覆盖」不算「国内源」——
把它算进来会让黄金/加密品种被改写成 6 位代码。因此注册表同时有 `markets`（能力）与 `domestic`（口径）。

## 四、Baostock 数据源

- 文件：`pa_agent/data/baostock_source.py`（`BaostockSource`），复用 `eastmoney_baostock.py` 里已有的
  `_BaostockSession`（类级锁 + 一次登录 + 重试），与东财的兜底路径**共用同一个 socket 会话**。
- 周期：`1d / 1w / 1M / 5m / 15m / 30m / 1h`，`4h` 由 1h 重采样。指数只有日线以上（分钟线会被拒绝）。
- 复权：跟随 `general.kline_adjust`（qfq→adjustflag=2，hfq→1，none→3），映射只写在
  `eastmoney_baostock.baostock_adjust_flag()`；`akshare_source` 早期那份映射把 hfq 与 none 写反了（已修）。
- 成交量单位：Baostock 返回「股」，本项目其余 A 股源统一用「手」，所以 `BaostockSource` 统一 `/100`
  （实测 600519 2026-11-02：Baostock 8269122 股 vs 东财 82691 手）。
- 收盘判定：日线/分钟线看「是不是今天 + 在不在连续竞价时段」；**周线按 ISO 周**、**月线按自然月**判断，
  因为 Baostock 把周线时间戳打成周内最后一个交易日、月线打成月末交易日。
- `connect()` 只验证包已安装，真正的 `bs.login()` 发生在首次查询——否则每次切数据源都会卡一次网络往返。

## 五、Binance 数据源

- 文件：`pa_agent/data/binance_source.py`（`BinanceSource`），走 `GET /api/v3/klines`，公开接口，无需 API Key。
- 品种：`BTCUSDT` / `btc/usdt` / `BTC-USDT` / `BINANCE:btcusdt` / `BTCUSDT.P` 都会被归一成 `BTCUSDT`；
  订阅时校验「像不像现货交易对」（必须是已知计价资产结尾）。
- 周期：`1m 5m 15m 30m 1h 4h 1d 1w 1M`；`1M` 的收盘是自然月，不套 `timeframe_to_seconds()`。
- 收盘判定：只有返回的**最后一根**可能是未完成 K 线；按区间毫秒算，周线/月线单独处理。
- 代理：`general.binance_proxy` → 为空则沿用 `general.tradingview_proxy` → 再空则自动探测
  （`pa_agent/data/proxy_env.py`，与 TradingView 共用同一套探测逻辑）。
- 失败语义：HTTP 4xx/5xx、非 JSON、网络不可达都转成 `DataSourceTransientError`，由刷新循环退避重试。

## 六、新增一个数据源要改什么

1. 在 `pa_agent/data/sources_registry.py` 的 `SOURCE_SPECS` 里加一条 `SourceSpec`（`DataSourceKind` Literal 也补上）。
2. 在 `pa_agent/data/factory.py` 的 `create_data_source()` 加一个分支（延迟导入 + 构造）。
3. 在 `pa_agent/config/settings.py` 的 `DataSourceKind` Literal 补上（`_coerce_legacy_data_source` 现在查 `ALL_KINDS`，不用改）。
4. 写 `tests/unit/test_<name>_source.py`；注册表不变量由 `tests/unit/test_sources_registry.py` 守护。

GUI 下拉、节流、占位提示、周期回落、默认品种、标签都由注册表自动生效，不需要再动 `main_window.py`。

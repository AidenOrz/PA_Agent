## 二、总体评价

这是一个**工程化程度显著高于同类个人/小型项目**的桌面 AI 工具：

- **测试文化好**：约 1000 个测试绝大多数在断言真实行为而非 smoke；property 测试钉住「不下单不变量」等真约束；conftest 把 settings 指到 tmp 防止测试覆盖用户真实 API key（DPAPI 副作用），网络测试全 mock、真实网络只留 `live` 标记。
- **工程卫生好**：conventional commits 中文规范、.gitignore 分层清晰、pre-commit 拦截明文密钥、git 依赖 pin 到 commit 并写明原因、settings/记录全链路原子写（mkstemp+fsync+os.replace）、路径净化防逃逸。
- **安全设计上乘**：DPAPI 加密主 Key、日志双层脱敏（注册值+形态兜底正则）、SECURITY.md 对残留风险的披露诚实准确。
- **AI 管线工程化**：jsonschema 缺失 fail-closed、「不下单」铁律 schema+不变量双重强制、§14 条款级解析、KV 缓存前缀动静分离确实落地。
- **GUI 线程纪律**：统一的「断信号→join→僵尸兜底→收割」QThread 回收协议，`_qobject_alive`/generation token 防 teardown 竞态。

**核心短板**不在「写了多少」，而在三点：① 基于自然语言**子串匹配**的判断反复出问题却仍在新增；② 「约定」停在单源各自正确，**跨源/跨路径口径没有交叉验收**；③ **门禁没有牙齿**——CI 中 ruff 是 advisory、black/e2e/uv.lock 都不进 CI，发布纯手工无校验，已造成 black 漂移和一次 lock 失同步的先例。

### P1（重要）

**数据层**
1. **4h 重采样按位置每 4 根切桶，A 股盘中所有 4h 历史桶跨日错位** — `ashare_common.py:420-432` 无交易日锚点；所有调用方都是「尾部 N 根再重采样」（`baostock_source.py:271-273`、`akshare_source.py:391-393`、`eastmoney_source.py:265-266` 等），A股每天恰好 4 根 1h，盘中尾取 `n*4+8` 必然落在某天中间 → 每个「4h 桶」= 第 k 日三根 + 第 k+1 日第一根，收盘价属于下一天，直接送 LLM。运行时已复现。
2. **Tushare 上证系指数后缀错误** — `tushare_source.py:72-78` 仅 `000300` 特判 `.SH`，`000016/000852/000905` 落入 `000→.SZ`（正确应为 `.SH`），预置指数必然拉空；深指 `399001/399006` 被当个股请求同样恒空。
3. **周线/月线未完成 bar 在收盘后被当已收盘 K1，且与 Baostock 口径相反** — `ashare_common.py:115-124` 对 `1w/1M` 用「15:00 之后即 closed」；`bar_close_wait.py:186-187` 直接短路 → 周三晚上的半截周线/月线参与 EMA/ATR 与分析；对比 `baostock_source.py:148-165` 按周期末判断，同一张图两个源给出不同 K1。

**AI 管线**
4. **重试「篡改检测」对带 markdown 围栏的输出完全失效（fail-open）** — `retry_feedback.py:32-40` `_try_parse_obj` 直接 `json.loads` 未过 `_strip_fences`；`validation_retry.py:200-201` 传入的也是未剥围栏原文。实测：模型用 ```json 围栏包住 JSON 时 `detect_cheat` 恒返回 `[]`，重试时反转 direction/cycle_position/gate_result 不会被发现。修复：解析前先 `_strip_fences`（与 validator 同源）。
5. **§1.3 混乱闸门只有提示词约束，程序侧无兜底** — `decision_nodes.py:487` 程序恒输出「否」；`decision_nodes.py:120` 安全闸门集合不含 1.3；`decision_tree.py:460-520` 不校验「1.3=是（或 1.2=否）vs gate_result=proceed」的矛盾。实测模型自写 gate_trace=混乱 + proceed → `validate('stage1')` 返回 Ok，阶段二照跑。上次修复只把提示词方向写对。建议在 `validate_gate_result_consistency` 补交叉校验。

## 四、根因主题与建议

1. **子串匹配反复出问题（§14 已修，同族仍在新增）** → 建立「凡匹配模型自然语言输出，一律词边界正则或结构化解析」的规约；优先改 `extract_feedback_targets`、pattern_routing、coherence_checks 方向重判三处。
2. **跨源/跨路径口径无交叉验收** → 补两类测试：同标的跨源成交量/涨跌幅一致性；4h/周线重采样边界（以交易日锚点重写 `resample_rows_to_4h`）。
3. **闸门一致性只写在提示词里** → 在 `validate_gate_result_consistency` 补 §1.3/§1.2 ↔ gate_result 程序化交叉校验；重估生产默认关闭 coherence/semantic 开关的决定（至少默认开核心三项）。
4. **脱敏/归一化多套实现并存** → 六类凭据收敛为一个共享脱敏注册表，日志与所有落盘路径（PendingWriter、debug 导出）统一复用；akshare 私有副本收敛回 `ashare_common`。
5. **门禁装上牙齿** → CI 加 black --check、ruff 转硬门禁（或白名单收敛 197 条）、`uv sync --frozen`、cache/timeout/concurrency、e2e 进 nightly；release 加 SHA256 与（可选）CI 打包 job。
6. **追问链路收尾** → closeEvent 停 `_ChatWorker`、取消走独立信号、删 `conversation_widget.py` 死代码、清理遮蔽 `QThread.finished` 的自定义信号命名。
7. **拆分 main_window.py** → 优先抽出 worker 生命周期管理（断信号-join-僵尸-收割协议已在四处重复）。
